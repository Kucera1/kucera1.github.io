# Web – Jaroslav Kučera

Jednostránkový web pro freelance služby: automatizace a reporty v Pythonu pro malé firmy.

Čisté statické HTML a CSS bez frameworku, bez build kroku a bez externích skriptů, fontů či měření
návštěvnosti. Funguje lokálně i na libovolném statickém hostingu (např. GitHub Pages).

## Jak otevřít lokálně

Dvojklikem otevřete soubor `index.html` v prohlížeči. Nic dalšího není potřeba.

## Soubory

- `index.html` – obsah stránky
- `style.css` – vzhled (světlý i tmavý režim podle nastavení systému)
- `assets/panel.png` – screenshot ovládacího panelu z ukázky
  [portfolio-report-demo](https://github.com/Kucera1/portfolio-report-demo) (vymyšlená data)
